# HungaRock honlap – első változat

## Használat
- Nyisd meg az `index.html` fájlt böngészőben a helyi előnézethez.
- A `style.css` tartalmazza a dizájnt.
- A `script.js` a mobilmenüt, az évet és egy egyszerű helyi számláló-demót kezeli.

## Személyre szabás
1. Cseréld ki a fotóhelyőrzőket saját képekre.
2. Írd át a tagok neveit.
3. Frissítsd a koncertlistát.
4. Cseréld ki a YouTube- és Facebook-linkeket a tényleges oldalakra.
5. A látogatottságmérő jelenleg csak az adott böngészőben tárolt demó. Valódi, minden látogatót összesítő számlálóhoz külső szolgáltatás vagy analitikai megoldás szükséges.

## Ingyenes közzététel
A projekt feltölthető GitHub Pages-re. A GitHub Free esetén nyilvános repository szükséges.
